## Publish to GitHub Pages (5 minutes)

1. Create a new **public** repository on GitHub (e.g. `owensboro-dumpster-guide`).
2. Upload the contents of this folder so that `index.html` sits at the **root**
   of the repository (keep the `images/` folder next to it).
3. Go to **Settings → Pages**.
4. Under "Build and deployment", set Source to **Deploy from a branch**,
   Branch to **main** (or master), folder to **/ (root)**. Click Save.
5. After ~1 minute your page is live at
   `https://<your-username>.github.io/<repo-name>/`.
